# DLP Live Map

A generic, mobile-first Disneyland Paris live map and attraction checklist.

## Included
- Detailed original illustrated resort map covering Disneyland Park and Disney Adventure World
- Interactive attraction/show/character markers directly on the map
- Tap a marker to mark an experience complete
- Completed markers turn green
- Resort / Disneyland Park / Disney Adventure World map focus controls
- 1×–3× zoom, pinch/scroll-style zoom, and drag-to-pan
- Live wait times from Queue-Times when available
- Attractions remain visible when live wait data is unavailable
- List and checklist views synchronized with the map
- Search and filters for park, type, wait status, and completion
- Progress saved locally on the device

## Map artwork
The map artwork is an original illustrated asset created for this app. It is designed to evoke a detailed theme-park guide while avoiding redistribution of Disneyland Paris' copyrighted official map artwork.

The park geography is based on Disneyland Paris' published park layout and current park/world structure. The illustration is not an official Disney map.

## Run
Open `index.html` in a browser or deploy the folder to GitHub Pages.

## Live waits
The app requests the Disneyland Paris park feeds from Queue-Times in the browser. If the live feed is unavailable, the catalog and checklist continue to work.
